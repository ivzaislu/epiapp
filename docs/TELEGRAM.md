# Telegram: бот, администратор и приглашения

EpiApp использует Telegram для:

- bootstrap-администратора;
- приглашения ребёнка и второго родителя;
- безопасного входа в Telegram Mini App;
- одноразовых кодов подключения Android;
- уведомлений и эскалаций.

## Создание бота

1. Откройте официальный `@BotFather`.
2. Выполните `/newbot`.
3. Задайте имя и username.
4. Сохраните bot token локально.

Bot token — секрет с полномочиями вашего бота. Не отправляйте его другим людям и не коммитьте `.env`.

## TELEGRAM_ADMIN_ID

`TELEGRAM_ADMIN_ID` — числовой user ID владельца/первого администратора. Это не `@username`.

Узнать ID можно любым доверенным способом. Если используете Bot API самостоятельно, сделайте это до запуска EpiApp long polling: напишите созданному боту сообщение и прочитайте `message.from.id` через `getUpdates`. Не публикуйте URL с bot token и удалите shell history, если вводили токен прямо в командной строке.

Пример production ENV:

```dotenv
TELEGRAM_BOT_TOKEN=...
TELEGRAM_ADMIN_ID=123456789
APP_BASE_URL=https://epiapp.example.com
```

## Первый запуск

После старта EpiApp напишите своему боту:

```text
/start
```

Аккаунт, чей ID совпадает с `TELEGRAM_ADMIN_ID`, получает роль `admin` без отдельного приглашения.

## Приглашение семьи

Администратор использует кнопки:

```text
👶 Пригласить ребёнка
👨‍👩‍👧 Пригласить родителя
```

Бот выдаёт одноразовую Telegram start-ссылку. Приглашение действует 24 часа и закрепляет Telegram ID пользователя за ролью после принятия.

## Android

После того как Telegram-аккаунт уже имеет роль, пользователь нажимает:

```text
📲 Подключить Android
```

Бот присылает:

```text
Сервер:
https://epiapp.example.com

Одноразовый код:
123 456
```

Код действует 5 минут и используется один раз. Универсальный APK просит именно эти два значения.

## Отзыв доступа

Администратор может выполнить:

```text
/revoke TELEGRAM_ID
```

Для приглашённого пользователя это отзывает его семейный доступ и связанные Android device credentials. `TELEGRAM_ADMIN_ID` через бот удалить нельзя — его меняют только в production ENV.

## Важные ограничения Telegram

Бот не может гарантировать звук уведомления: пользователь может выключить уведомления, включить DND или ограничить Telegram. Поэтому детский Android APK использует независимые локальные alarms, а Telegram остаётся вторым каналом для родителей.

Название препарата и дозы не включаются в обычные Telegram-уведомления EpiApp; они доступны внутри защищённого приложения.
