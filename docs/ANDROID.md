# Android-клиент EpiApp UP

Проект находится в `android/`. Kotlin-приложение открывает веб-кабинет в WebView, получает расписание из кабинета и планирует локальные звуковые напоминания Android. Экспериментальная сборка в этой ветке имеет версию `0.7.5-up.3` и требует Android 8.0 или новее на телефоне.

## Подключение

1. Установите APK. Откройте Telegram-бота своего экземпляра EpiApp с уже выданной ролью.
2. Нажмите **Подключить Android → Открыть в EpiApp** и подтвердите открытие приложения, если Telegram или браузер попросит.
3. Если переход не сработал, откройте ссылку в системном браузере и нажмите **Открыть EpiApp**. Ссылка живёт пять минут и используется один раз.
4. При смене сервера или домена запросите у бота новую ссылку подключения.

При подключении APK получает ключ устройства. Сервер хранит его хеш, а клиент сохраняет ключ в приватных настройках Android. При последующих запусках ключ используется для получения веб-сессии. Доступ отозванной учётной записи блокируется сервером.

## Напоминания ребёнку и отметки

- Сборка `0.7.5-up.3` показывает обычное звуковое уведомление с вибрацией в отдельном канале «Ребёнку — приём лекарства». Полноэкранное окно и самостоятельный запуск Activity удалены. Нажатие открывает кабинет с восстановлением сессии и ожиданием записи cookie.
- Расписание сохраняется из API сразу при подключении и восстановлении сессии, независимо от загрузки WebView. Каждое событие ставит следующее на следующий календарный день в часовом поясе семьи. Отметка за вчера не выключает сегодняшний сигнал. Несколько препаратов на одно время сохраняют независимые события.
- При открытии кабинета и получении свежих отметок локальные повторы пересчитываются. Подтверждённый приём отменяет уведомление и оставшиеся повторы за этот день. Само уведомление не создаёт отметку: ребёнок подтверждает приём в кабинете, а сервер сохраняет его.
- Детское устройство регистрирует UnifiedPush только для тихого сигнала обновления расписания. Родительские сообщения ребёнку не отправляются. После изменения схемы или отметки сервер отправляет сигнал, приложение загружает актуальное расписание отдельным Worker. Резервная синхронизация через WorkManager — примерно каждые 15 минут; Android может её задерживать.
- Уже сохранённое расписание работает без интернета. Для новых настроек и подтверждений нужна сеть. Если телефон офлайн, он ещё не знает об изменениях на сервере и продолжает старое расписание.
- В детском кабинете показаны запрет уведомлений, отключённый звук канала и отсутствие разрешения точного времени. Есть кнопки системных настроек. Беззвучный режим, «Не беспокоить», громкость и системные ограничения приложение не обходит. Принудительная остановка через настройки Android останавливает фоновые события до следующего открытия.

### Проверка на телефоне

1. Обновить тестовый бэкенд до этой ветки и установить `0.7.5-up.3`. Из-за временного ключа CI обновление старого APK может потребовать переустановки и повторного подключения.
2. Подключить именно детский профиль. Разрешить уведомления, звук и точное время по подсказкам кабинета.
3. В родительской схеме поставить тестовый приём на ближайшие 2–3 минуты. При доступной сети дождаться обновления на детском телефоне; для первой проверки открыть детский кабинет, затем свернуть и заблокировать экран.
4. Проверить звук, вибрацию и отсутствие самостоятельного полноэкранного окна. Нажать уведомление: должен открыться кабинет без повторного входа. Подтвердить приём и проверить, что повторы прекратились.
5. Проверить работу по сохранённому расписанию без сети, следующий день, несколько препаратов на одно время и изменение расписания родителем при закрытом детском приложении.

## Оповещения родителю

В родительском кабинете раздел **Оповещения** показывает подтверждения за последние сутки и текущие напоминания. На экране **Напоминания** отдельно настраиваются отправка в Telegram и оповещения на этом телефоне. Кнопка **Проверить оповещение** отправляет локальное тестовое уведомление. Там же видны разрешение Android и время последней успешной проверки.

Родительское приложение проверяет сервер через WorkManager примерно каждые 15 минут в фоне и при обновлении открытого кабинета. Android может задерживать фоновые задания из-за энергосбережения. Для фоновой проверки нужны сеть и сохранённое подключение к серверу. Первая проверка устанавливает начальную точку отслеживания, чтобы подключение не вызывало поток старых уведомлений.

Оповещения родителя используют отдельные каналы Android и открывают кабинет по нажатию. Перед каждым напоминанием сервер проверяет наличие отметки. При следующей успешной проверке приложение отменяет оповещение об отсутствии отметки, если приём уже подтверждён. После отзыва доступа фоновая проверка прекращается.

## Сборка APK

Откройте каталог `android/` в Android Studio с JDK 17 и Android SDK 35. Для debug APK выберите **Build APK** или выполните с совместимым Gradle из корня репозитория:

```bash
gradle -p android :app:assembleDebug
```

APK появится в `android/app/build/outputs/apk/debug/app-debug.apk`. Выпуск подписанной сборки описан в [RELEASE.md](RELEASE.md).

## Редактирование схемы

В родительском кабинете откройте «Схема». Список показывает названия препаратов и их расписание. Нажмите на препарат, измените его название, время или дозу и нажмите «Сохранить препарат». Новый препарат попадает в список только после сохранения. При выходе с несохранёнными изменениями приложение просит подтверждение; удаление препарата и уменьшение количества приёмов также подтверждаются.

Строка с именем ребёнка открывает настройки имени и часового пояса. Пояс выбирается из списка IANA, поддерживаемого сервером: можно искать по идентификатору (`Europe/Berlin`) или русскому названию одного из распространённых городов («Берлин», «Москва»). Поиск не меняет выбранный пояс. Смещение UTC показано на текущую дату; переходы на летнее и зимнее время учитываются правилами выбранного пояса. Изменения интерфейса загружаются с сервера и доступны в существующем Android-приложении после повторного открытия кабинета.

## Скачивание из Telegram

В личном чате с ботом нажмите «📥 Скачать приложение» или отправьте `/download`. Бот присылает установочный APK и инструкцию. После установки нажмите «📲 Подключить Android». APK общий для всех ролей; при подключении сервер выдаёт права текущего Telegram-аккаунта. Сборка для распространения задаётся через `ANDROID_APK_URL`, в этой ветке по умолчанию используется `v0.7.5-up.3`.

В родительском кабинете сообщения и настройки собраны в одном разделе «Уведомления»: вкладка «Сообщения» показывает подтверждения и текущие напоминания, вкладка «Настройки» содержит интервалы, Telegram и уведомления на этом телефоне.

## Экспериментальная сборка UnifiedPush

Ветка `unifiedpush-vapid` использует EpiApp UP (`org.epiapp.android.unifiedpush`, версия `0.7.5-up.3`). Она устанавливается рядом с основной и требует тестовый бэкенд из этой ветки. Встроенный доставщик UnifiedPush регистрируется в Google Play services с ключом VAPID, который автоматически создаёт бэкенд. Firebase-проект и отдельное приложение-доставщик не нужны. Подробный план проверки: [PUSH.md](PUSH.md).
