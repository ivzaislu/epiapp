# Android-клиент EpiApp в ветке web-next

Проект находится в `android/`. Kotlin-приложение открывает веб-кабинет в WebView, получает расписание из кабинета и планирует будильники Android. Экспериментальная сборка в этой ветке имеет версию `0.7.5-up.1` и требует Android 8.0 или новее на телефоне.

## Подключение

1. Установите APK. Откройте Telegram-бота своего экземпляра EpiApp с уже выданной ролью.
2. Нажмите **Подключить Android → Открыть в EpiApp** и подтвердите открытие приложения, если Telegram или браузер попросит.
3. Если переход не сработал, откройте ссылку в системном браузере и нажмите **Открыть EpiApp**. Ссылка живёт пять минут и используется один раз.
4. При смене сервера или домена запросите у бота новую ссылку подключения.

При подключении APK получает ключ устройства. Сервер хранит его хеш, а клиент сохраняет ключ в приватных настройках Android. При последующих запусках ключ используется для получения веб-сессии. Доступ отозванной учётной записи блокируется сервером.

## Напоминания и отметки

- После успешной загрузки детского кабинета расписание сохраняется на телефоне. Для точного времени будильников проверьте разрешения Android на уведомления и точные будильники. Для полноэкранного показа проверьте системное разрешение, если оно доступно.
- Уже запланированные будильники могут сработать без сети. Для новых отметок, проверки доступа и обновления расписания нужна связь с сервером. Текущая версия формирует ближайшие сигналы из сохранённого расписания. Для повторной синхронизации откройте детский кабинет, в том числе после изменения схемы или напоминаний.
- Родитель видит статистику и управляет схемой. Отметку отправляет детский профиль после подтверждения в кабинете.

## Оповещения родителю

В родительском кабинете раздел **Оповещения** показывает подтверждения за последние сутки и текущие напоминания. На экране **Напоминания** отдельно настраиваются отправка в Telegram и оповещения на этом телефоне. Кнопка **Проверить оповещение** отправляет локальное тестовое уведомление. Там же видны разрешение Android и время последней успешной проверки.

Родительское приложение проверяет сервер через WorkManager примерно каждые 15 минут в фоне и при обновлении открытого кабинета. Android может задерживать фоновые задания из-за энергосбережения. Для фоновой проверки нужны сеть и сохранённое подключение к серверу. Первая проверка устанавливает начальную точку отслеживания, чтобы подключение не вызывало поток старых уведомлений.

Оповещения родителя используют отдельные каналы Android и открывают кабинет по нажатию. Перед каждым напоминанием сервер проверяет наличие отметки. При следующей успешной проверке приложение отменяет оповещение об отсутствии отметки, если приём уже подтверждён. После отзыва доступа фоновая проверка прекращается.

## Сборка APK

Откройте каталог `android/` в Android Studio с JDK 17 и Android SDK 35. Для debug APK выберите **Build APK** или выполните с совместимым Gradle из корня репозитория:

```bash
gradle -p android :app:assembleDebug
```

APK появится в `android/app/build/outputs/apk/debug/app-debug.apk`. Выпуск подписанной сборки описан в [RELEASE.md](RELEASE.md).

## Редактирование схемы

В родительском кабинете откройте «Схема». Список показывает названия препаратов и их расписание. Нажмите на препарат, измените его название, время или дозу и нажмите «Сохранить препарат». Новый препарат попадает в список только после сохранения. При выходе с несохранёнными изменениями приложение просит подтверждение; удаление препарата и уменьшение количества приёмов также подтверждаются.

Строка с именем ребёнка открывает настройки имени и часового пояса. Пояс выбирается из списка IANA, поддерживаемого сервером: можно искать по идентификатору (`Europe/Berlin`) или русскому названию одного из распространённых городов («Берлин», «Москва»). Поиск не меняет выбранный пояс. Смещение UTC показано на текущую дату; переходы на летнее и зимнее время учитываются правилами выбранного пояса. Изменения интерфейса загружаются с сервера и доступны в существующем Android-приложении после повторного открытия кабинета.

## Скачивание из Telegram

В личном чате с ботом нажмите «📥 Скачать приложение» или отправьте `/download`. Бот присылает установочный APK и инструкцию. После установки нажмите «📲 Подключить Android». APK общий для всех ролей; при подключении сервер выдаёт права текущего Telegram-аккаунта. Сборка для распространения задаётся через `ANDROID_APK_URL`, в этой ветке по умолчанию используется `v0.7.5-up.1`.

В родительском кабинете сообщения и настройки собраны в одном разделе «Уведомления»: вкладка «Сообщения» показывает подтверждения и текущие напоминания, вкладка «Настройки» содержит интервалы, Telegram и уведомления на этом телефоне.

## Экспериментальная сборка UnifiedPush

Ветка `unifiedpush-vapid` использует EpiApp UP (`org.epiapp.android.unifiedpush`, версия `0.7.5-up.1`). Она устанавливается рядом с основной и требует тестовый бэкенд из этой ветки. Встроенный доставщик UnifiedPush регистрируется в Google Play services с ключом VAPID, который автоматически создаёт бэкенд. Firebase-проект и отдельное приложение-доставщик не нужны. Подробный план проверки: [PUSH.md](PUSH.md).
