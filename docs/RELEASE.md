# Подписанная Android-сборка для web-next

APK этого проекта собирается из модуля `android/app`. Для тестового APK см. [ANDROID.md](ANDROID.md).

Для постоянной установки откройте каталог `android/` в Android Studio и выберите **Build → Generate Signed App Bundle / APK → APK → app → release**. Если вы обновляете существующий APK, используйте прежний ключ подписи и увеличьте `versionCode` в `android/app/build.gradle.kts`. Храните ключ и пароли отдельно от репозитория.

Проверьте готовый APK через `apksigner verify --print-certs`. Для обновления должны совпадать идентификатор приложения и сертификат. Сборка, подписанная другим ключом, потребует новой установки и повторного подключения к боту.

Тестовый APK публикует workflow `Android debug prerelease` при изменении `android/app/build.gradle.kts` на `web-next`. Он также запускается вручную через Actions. Тег имеет вид `v0.7.3-debug`, релиз отмечен как prerelease и содержит APK, контрольную сумму и сведения о сертификате. Повышайте версию перед следующим пререлизом. Debug-ключ GitHub Actions может меняться между запусками, поэтому подпись установленного APK и нового пререлиза может различаться.
