# Безопасность self-hosted EpiApp

EpiApp хранит семейные данные и должен рассматриваться как приватный сервис.

## Секреты

Секреты:

- `TELEGRAM_BOT_TOKEN`;
- SSH/server credentials;
- production `.env`;
- Android release signing key и его пароли.

Не коммитьте их в Git. Если bot token когда-либо оказался в публичном репозитории/issue/log, отзовите его через BotFather и выпустите новый.

`TELEGRAM_ADMIN_ID` сам по себе не является секретом, но production ENV всё равно храните как секрет из-за bot token.

## Сетевой периметр

Рекомендуемая схема:

```text
Internet -> 80/443 reverse proxy -> private EpiApp :3000
```

Не публикуйте Node `3000` напрямую. Docker Compose из репозитория не выставляет этот порт на хост. systemd по умолчанию использует `127.0.0.1`.

Оставьте SSH доступ только так, как требуется вашему серверу. Не очищайте firewall вслепую командами вроде `iptables -F`.

## HTTPS

Telegram Mini App и Android pairing требуют HTTPS. Универсальный APK отказывается подключаться к `http://`.

Следите за автоматическим продлением сертификата и периодически проверяйте public `/healthz`.

## Авторизация

Web/Telegram:

- backend проверяет подписанный Telegram `initData`;
- после проверки выдаётся `HttpOnly; Secure; SameSite=Strict` cookie;
- роль сверяется с серверным access-list.

Android:

- pairing code одноразовый, шестизначный и живёт 5 минут;
- endpoint ограничивает число попыток;
- после pairing выдаётся случайный 256-bit device-token;
- сервер хранит только SHA-256 hash token;
- raw token хранится на Android в зашифрованном виде через Android Keystore;
- каждый native session/schedule запрос повторно проверяет, что владелец устройства всё ещё имеет доступ.

## Отзыв

При отзыве приглашённого Telegram-пользователя связанные с ним Android credentials отзываются. Администратор из `TELEGRAM_ADMIN_ID` меняется через ENV.

Если телефон потерян, отзовите доступ/устройство как можно быстрее. До добавления отдельного UI управления конкретными устройствами отзыв пользователя — основной аварийный механизм.

## Backup

Backup JSON содержит историю отметок, роли и hashes устройств. Сам по себе hash device-token не позволяет восстановить raw token, но backup всё равно является приватными семейными данными.

ENV backup содержит bot token и требует более строгой защиты.

## Android signing

Не публикуйте release keystore. Один стабильный signing key нужен для безопасных обновлений одного application ID. Потеря ключа означает, что существующую установку нельзя штатно обновлять APK с новым ключом.

## Обновления ОС

Не держите production на EOL ОС без необходимости. Особенно не заменяйте системную glibc вручную ради Node.js. Предпочтительнее поддерживаемая ОС или контейнеризированный deployment.

## Не медицинское устройство

EpiApp фиксирует пользовательские отметки и запускает напоминания. Он не может доказать фактический приём лекарства, не назначает дозу и не должен автоматически давать рекомендации при пропуске.
