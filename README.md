# EpiApp v1.1

Семейное приложение для отметки двух ежедневных приёмов лекарства ребёнком и уведомления родителей в Telegram.

Приложение **не назначает дозировку, не меняет схему лечения и не подсказывает, что делать при пропущенной дозе**. Оно хранит только схему, которую внесли родители, и фиксирует отметки пользователя.

## Основной функционал

- Telegram Mini App авторизация вместо публичного доступа;
- bootstrap-администратор из `TELEGRAM_ADMIN_ID`;
- одноразовые приглашения ребёнка и второго родителя через Telegram;
- постоянные кнопки меню бота по роли;
- роли `child`, `parent`, `admin`;
- настраиваемая таблетница: препарат, отдельная утренняя и вечерняя доза, время и часовой пояс;
- оба родителя могут менять таблетницу и расписание;
- ребёнок видит препарат и нужную дозу перед подтверждением;
- защита от повторной отметки одного приёма в тот же календарный день;
- статистика за 7/30 дней и API до 90 дней;
- статистика отдельно по утру и вечеру, число пропущенных отметок и серия полных дней;
- второй родитель видит ту же статистику, что администратор;
- журнал последнего изменения настроек с Telegram ID и ролью изменившего;
- Telegram-уведомления администратору и всем пользователям роли `parent`;
- мгновенный отзыв доступа;
- серверная проверка подписанного Telegram `initData`;
- подписанная `HttpOnly; Secure; SameSite=Strict` cookie-сессия;
- Node.js слушает только `127.0.0.1:3000`, наружу приложение публикуется через Nginx/HTTPS;
- JSON-хранилище с атомарной записью;
- unit/integration-тесты на Node.js 18.19.1, 20 и 22.

Название препарата и дозы **не включаются в Telegram-уведомления**. Они доступны только внутри авторизованного EpiApp.

## Роли

| Роль | Возможности |
| --- | --- |
| `child` | видеть таблетницу и статус, отмечать утро/вечер |
| `parent` | видеть статус и статистику, менять препарат/дозы/расписание, получать уведомления |
| `admin` | всё родительское + приглашать пользователей, смотреть список и отзывать доступ |

Прямое открытие `https://epiapp.duckdns.org` не даёт доступа к данным: приватные API требуют валидную серверную Telegram-сессию.

## Telegram-бот

Администратор пишет боту `/start`. После этого появляется меню:

- `📱 Открыть EpiApp`
- `👶 Пригласить ребёнка`
- `👨‍👩‍👧 Пригласить родителя`
- `📊 Статистика`
- `👥 Пользователи`
- `ℹ️ Помощь`

У второго родителя меню содержит `Открыть EpiApp`, `Статистика` и `Помощь`. У ребёнка — только безопасный вход в EpiApp и помощь.

Команды продолжают работать:

```text
/start
/stats
/invite_child
/invite_parent
/users
/revoke TELEGRAM_ID
/help
```

Приглашение одноразовое и действует 24 часа. Администратор пересылает invite-ссылку нужному человеку. После принятия Telegram ID закрепляется за ролью.

Отзыв доступа:

```text
/revoke 123456789
```

Отзыв применяется сразу: роль при каждом приватном API-запросе сверяется с серверным access-list.

## Таблетница

В родительском кабинете оба пользователя роли `parent` и `admin` могут указать:

- имя ребёнка;
- название препарата;
- дозу утром;
- дозу вечером;
- время утреннего приёма;
- время вечернего приёма;
- часовой пояс.

Поля дозы текстовые, например `1 таблетка`, `500 мг` или другая формулировка назначения. EpiApp не интерпретирует и не пересчитывает дозу.

## Статистика

Родительский кабинет показывает:

- долю отмеченных ожидаемых приёмов за 7 дней;
- долю за 30 дней;
- отдельно утро и вечер;
- количество пропущенных отметок;
- количество полных дней подряд;
- последние 14 календарных дней по слотам.

Текущий слот считается ожидаемым только после наступления его времени по настроенному часовому поясу либо если отметка уже сделана. Поэтому вечер заранее не считается пропущенным.

Статистика начинается с первой сохранённой настройки или первой отметки в имеющихся данных, чтобы новый сервер не показывал фиктивные пропуски за дни до начала использования.

В Telegram родитель/администратор может нажать `📊 Статистика` и получить краткую сводку за 7 дней.

## Telegram Mini App безопасность

Браузер передаёт серверу `Telegram.WebApp.initData`. Сервер проверяет HMAC-подпись и `auth_date`; `initDataUnsafe` не используется как источник доверия.

После проверки сервер выдаёт подписанную cookie-сессию:

```text
HttpOnly; Secure; SameSite=Strict
```

Сессия содержит Telegram ID и срок действия. Роль каждый раз берётся с сервера.

## Production ENV

Файл:

```text
/etc/epiapp/epiapp.env
```

Минимальная конфигурация:

```dotenv
TELEGRAM_BOT_TOKEN=ВАШ_ТОКЕН
TELEGRAM_ADMIN_ID=ВАШ_ЧИСЛОВОЙ_TELEGRAM_ID
APP_BASE_URL=https://epiapp.duckdns.org
HOST=127.0.0.1
PORT=3000
DATA_FILE=/var/lib/epiapp/epiapp.json
```

`PARENT_PIN` из ранней версии больше не используется и может оставаться в старом ENV без эффекта.

Не публикуйте bot token и не коммитьте production ENV.

## Установка / обновление

Нужен systemd и Node.js 18.19+.

```bash
git checkout v-1.1
git pull origin v-1.1
sudo ./install.sh
```

Installer сохраняет существующий `/etc/epiapp/epiapp.env`, копирует приложение в `/opt/epiapp`, перезапускает `epiapp.service` и проверяет `/healthz`.

Проверка:

```bash
sudo systemctl status epiapp --no-pager
sudo journalctl -u epiapp -n 50 --no-pager
curl http://127.0.0.1:3000/healthz
```

Ожидается:

```json
{"ok":true}
```

И в журнале:

```text
EpiApp: http://127.0.0.1:3000
EpiApp Telegram bot: @YourBot
```

## Nginx + HTTPS

Проверенная схема:

```text
Internet
  -> epiapp.duckdns.org :80/:443
  -> Nginx
  -> 127.0.0.1:3000
  -> EpiApp
```

Порт `3000` не нужно открывать публично. Пример Nginx-конфига находится в `deploy/nginx/epiapp.conf.example`.

Проверки:

```bash
curl https://epiapp.duckdns.org/healthz
curl -I https://epiapp.duckdns.org/
sudo certbot renew --dry-run
```

Публично нужны TCP 80/443. Не используйте `iptables -F` на удалённом сервере.

## Ubuntu 18.04 / Node.js

Для ветки `v-1.1` минимальная проверяемая версия — Node.js **18.19.0**. CI прогоняет Node.js 18.19.1, 20 и 22.

Ubuntu 18.04 использует старую glibc; современные официальные Node.js binaries могут требовать более новую libc. Не обновляйте системную glibc вручную ради EpiApp. На legacy-сервере допустима совместимая community-сборка Node.js Unofficial Builds `linux-x64-glibc-217` с проверкой SHA256. При возможности предпочтительнее обновить ОС.

## Уведомления

После отметки ребёнком администратор и все пользователи роли `parent` получают сообщение вида:

```text
✅ Аня: утренний приём отмечен в 08:04.
```

Название лекарства, дозировка и диагноз в Telegram не отправляются.

## Ограничения и следующие шаги

Версия рассчитана на один семейный серверный экземпляр. Access-list, приглашения, таблетница и отметки хранятся в одном JSON-файле. Нужны регулярные резервные копии `/var/lib/epiapp/epiapp.json` и защита SSH/server credentials.

Хорошие следующие улучшения: напоминания при неотмеченном приёме после настраиваемого интервала, резервное копирование/экспорт, журнал событий доступа и опциональный учёт остатка препарата без автоматического изменения лечебной схемы.
